# Product Requirement Document

## 1. Problem

기존 여행 콘텐츠는 다음과 같은 문제가 있다:

- 인스타: 정보 구조 부족
- 블로그: 읽기 부담 큼
- 커뮤니티: 일정 단위 공유 부족

사용자는 "실제 다녀온 일정"을 빠르게 참고할 수 있는  
구조화된 콘텐츠를 원한다.

---

## 2. Target User

- 여행을 자주 가는 사용자
- 다른 사람의 실제 여행 루트를 참고하고 싶은 사용자
- 자신의 여행 경험을 기록하고 공유하고 싶은 사용자

---

## 3. Core User Loop

1. 피드에서 여행 일정 탐색
2. 마음에 드는 일정 저장 또는 좋아요
3. 작성자 프로필 탐색
4. 팔로우
5. 자신의 여행 일정 작성
6. 피드에 게시 → 반복

---

## 4. Content Model

게시글 = 여행 일정 카드 (Itinerary Post)

구성:

- 대표 이미지 (필수)
- 여행 제목
- 여행 기간 (선택)
- Day별 일정
- 각 Day에 대한 설명
