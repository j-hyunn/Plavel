# Travel Itinerary Feed

실제 다녀온 여행 일정을 공유하는 피드 커뮤니티

## 🎯 Product Concept

사진 중심 SNS가 아닌  
**여행 일정(Itinerary) 중심 커뮤니티**

사용자는 자신이 실제로 다녀온 여행의 Day별 일정을  
이미지와 함께 공유하고, 다른 사용자의 일정을 참고할 수 있다.

---

## ✨ Core Features (MVP)

- 닉네임 기반 사용자 시스템
- 여행 후기 일정 게시글 작성
- 이미지 필수 업로드
- Day 단위 일정 구성
- 최신순 피드
- 좋아요 / 댓글
- 게시글 저장(북마크)
- 사용자 팔로우
- 프로필 페이지

---

## 🚫 Out of Scope (MVP 제외)

- 여행 계획 공유
- 지도 기능
- 검색 기능
- DM / 채팅
- 알림 시스템
- 추천 알고리즘
